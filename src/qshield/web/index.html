    Menambahkan panel forensik di kartu hasil: tiap tag EMVCo beserta panjang, keterangan, dan isinya. Permintaannya menyertakan include_tlv; tanpa mode ini server tidak mengirimkannya sama sekali.
    Mode replay ditandai terbuka di tanggapan dan jejak audit. Ia tidak mengubah penilaian sedikit pun.
    Hanya berfungsi bila server dijalankan dengan QSHIELD_FIELD_MODE=on. Mode ini menyimpan payload mentah dan koordinat presisi — untuk kalibrasi tim sendiri, jangan pernah di lingkungan pengguna.
    Label SAMA untuk pemindaian berulang di merchant yang sama; label BERBEDA untuk merchant berbeda walau bersebelahan. Inilah kebenaran dasar yang dipakai analisisnya.
